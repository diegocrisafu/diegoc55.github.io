The NVIDIA mark identifies the vendor of Omniverse; it is not a separate Omniverse product logo. Cloud, AI, and machine learning use generic Lucide symbols. These branches are a map of tools and domains Diego used, not a diagram of confidential employer systems.

## Hover colors

The `color/` variants use brand hex values from Simple Icons’ `data/simple-icons.json`. Python’s two-color original is from [Devicon](https://github.com/devicons/devicon/blob/master/icons/python/python-original.svg), with `DEVICON-LICENSE`. The colored PowerShell asset is upstream `powershell_128.svg`, covered by the same Microsoft asset notice.

At rest, CSS makes the assets monochrome. Hover reveals their original color at 90% opacity with a faint matching background. Keyboard focus within an employer reveals that employer’s colors without adding 14 decorative tab stops. GitHub, Copilot and Unreal keep their native neutral identity; dark mode uses their reversed treatment. Generic Cloud, AI, and machine-learning colors are interface choices, not brand colors.

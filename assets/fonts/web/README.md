# Web fonts

Self-hosted copies of the portfolio's web fonts, so pages load without requests to Google Fonts or other third parties.

| Family           | Files                          | License                   |
| ---------------- | ------------------------------ | ------------------------- |
| Geist            | `geist-normal-400-600-*.woff2` | `OFL-Geist.txt`           |
| Instrument Serif | `instrument-serif-*.woff2`     | `OFL-InstrumentSerif.txt` |
| JetBrains Mono   | `jetbrains-mono-*.woff2`       | `OFL-JetBrainsMono.txt`   |

The files are the unmodified Latin and Latin Extended subsets served by the Google Fonts CSS API on September 11, 2026. The `@font-face` rules at the top of `style.css` keep the same `unicode-range` values. All three families are distributed under the SIL Open Font License 1.1.

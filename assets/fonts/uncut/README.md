# Uncut Sans

Designed by Kasper Nordkvist. The portfolio self-hosts the unmodified variable WOFF2 font with `font-display: swap` and uses its normal 300–700 weight range.

- Source: https://github.com/kaspernordkvist/uncut_sans
- Specimen: https://uncut.wtf/sans-serif/uncut-sans/
- License: `LICENSE.txt`, SIL Open Font License 1.1

No remote font service is loaded. Keep the license with the font when distributing the site. The previous web fonts are retained in the sibling `web` directory but are not used by the current stylesheet.

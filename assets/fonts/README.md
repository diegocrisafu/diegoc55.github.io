# Resume fonts

The classic resume uses Portfolio Resume Serif, a Latin subset of Liberation Serif
regular, bold, and bold italic. The derivative fonts have been renamed, retain
their original copyright notices, and are distributed under the SIL Open Font
License in `LICENSE`.

The source fonts came from the Liberation fonts included with LibreOffice.
The subset includes Latin characters and general punctuation for English and
French resume text. The PDF embeds only the glyphs it uses.

The Liberation Sans files are retained for the earlier resume layout.
